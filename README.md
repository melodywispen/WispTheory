# Wisp Theory
My DIY theory for stenography.
I made this years ago, but rediscovered it recently. I compiled all the words and phrases into one dictionary. It's over 7000 entries long.

Let me know if you choose to use Wisp Theory! In the meantime, I'll be updating this Read Me with rules from the theory as I dig through the dictionary.

Rules:
1. We use the number bar for strokes if we want to. Many entries have at least one number bar version.
2. To invert phrases, we use #-Z! "She will" inverted is "will she".
3. Translations reflect steno order. So if "she" is the first part of the phrase, then it should also be at the front of the chord. For example: "I believe" should have "I" before "believe". Some phrases, due to the way they are written in English, might, however, surround the pronoun chord.
4. We use asterisk mostly for past tense. Secondly for disambiguation.
5. If the brief is on the right side of the keyboard, it must be written using the number bar. This is to prevent conflicts with the Phoenix Theory dictionary I use.

# Mandatories:
Some briefs must be written a certain way to prevent conflicts with Phoenix Theory. These mandatory briefs are listed below:
1. Thing -> -78G
2. Things -> -78GZ
3. Will we -> HR*EG
4. leg -> HREG
